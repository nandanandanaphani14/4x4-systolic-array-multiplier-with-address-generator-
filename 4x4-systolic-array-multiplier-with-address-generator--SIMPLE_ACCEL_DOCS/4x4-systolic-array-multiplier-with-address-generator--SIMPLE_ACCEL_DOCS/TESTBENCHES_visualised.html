2The flow each testbench checks

Every job runs the same four phases. The golden testbenches load a random non-symmetric weight matrix, stream activation vectors, and compare each result against C = A × W computed by a plain nested loop. This animation illustrates weights loading bottom-first, activations streaming as a diagonal wavefront, partial sums descending, and results emerging and de-skewing onto one cycle.

Five phases, no FLUSH: COMPUTE follows WLOAD directly. Job length N + 13 = 17 cycles for a 4×4 product, or N + 9 = 13 cycles when the weight matrix has not changed since the last job and WLOAD is skipped altogether.

4How a single testbench is structured

All 11 testbenches share one reporting harness (tb_common.svh) and emit an identical, reviewable transcript. Press Replay to type one out; the anatomy is annotated below.

idle
Banner
DUT, sampling convention, and a numbered TEST PLAN (T1, T2, …) — states up front what will be proven.
Decoded stimulus + trace
Each transaction prints inputs and the observed output beside the expected value, so a passing run is reviewable, not just green.
Section tally
Tx ends: N checks, M errors [PASS] — every section reports its own count.
Section summary + TOTALS
A table of all sections, a grand TOTALS, and a single RESULT: PASS/FAIL line the regression script greps.
Two sampling conventions
A (registered outputs): drive after a posedge, consume at the next, then sample. B (delay lines / address buses): sample before the consuming edge — the only way to tell a wire from a 1-deep register. Each header states which it uses.
Golden model
From the fabric up, expected values are C = A×W from a plain nested loop with a random non-symmetric matrix — a design bug copied into the testbench is impossible, and any weight-row permutation fails.

5Directed 4×4 × 4×4 matrix multiply (T5)

The L3 testbench streams four activation vectors — treating A as a full 4×4 matrix — and checks the whole product against the golden model. Press Compute to fill C = A × W cell by cell; each cell is C[i][c] = Σr A[i][r]·W[r][c].

Rows 0–2 of C reproduce weight rows 0–2; the all-ones activation row 3 yields the column sums [28 32 36 40] — checkable by eye, which is the point of a directed case.
